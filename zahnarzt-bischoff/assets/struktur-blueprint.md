# Struktur-Blueprint: Zahnärzte Dr. Jörg & Annett Bischoff, Zahnarztpraxis
(Archetyp C zentriert-minimal · Welt W4 Klinisch-warm · Motion still)

- **Nav-Paradigma:** Scroll-Spy ohne sichtbare Nav — feiner vertikaler Strich-Indikator rechts,
  der bei Scroll mitwandert (zusätzlich nur Logo links + 1 Telefon-CTA). Stille Navigation = Vertrauen.
- **Sektions-Kopf:** Frage-Headline — jede Sektion startet mit der echten Patientenfrage
  („Was bedeutet ganzheitliche Zahnmedizin?" · „Wer behandelt mich?" · „Wie vereinbare ich einen Termin?").
- **Komponenten (dominant):** Akkordeon (+ Neben-Bauform: ein zentrierter Split-Block fürs Team).
- **Kontakt-Lösung:** Keine Karte — nur Adresse (Lönsweg 1) + großer „Termin nur telefonisch"-CTA.
- **Footer-Form:** Einzeilig minimal — Logo · Telefon/Adresse · Impressum-Link in einer Zeile.
- **Galerie-Form:** Keine Galerie. (Falls Praxis-Innenraum-Fotos → in den Team-Split, keine eigene Galerie.)
- **Sektions-Spine:**
  Hero(Line-Draw Zahn+Schmetterling, zentriert) → Philosophie(Frage + Fließtext-Zitat „ganzheitlich")
  → Behandlungsspektrum(Akkordeon 7 Leistungen) → Team(Split-Block, echtes Foto Dr. Jörg + Annett)
  → Hilfseinsatz(schmales Werte-/Charity-Band, Schmetterling-Motiv) → Sprechstunden(Zeit-Liste)
  → Kontakt(Adresse + „nur telefonisch"-CTA, keine Karte)

**Divergenz:** Spine ≠ letzte 3/Geschwister ✓ · Nav=Scroll-Spy & Kontakt=keine Karte (beide im Batch einzigartig) ✓ · 6/6 Achsen abweichend ✓.
