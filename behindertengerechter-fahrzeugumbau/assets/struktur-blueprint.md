# Struktur-Blueprint — Mobilitäts-Zentrum Mattes (Bau-Vertrag, Phase 1.6)
Archetyp G · Welt W1 Editorial-Ruhig. Die 7 Achsen sind verbindlich für Phase 4 und Soll für den
`struktur-divergenz-reviewer` (Phase 8).

| Achse | Wert | Begründung (echter Content) | ≠ Schwester KFZ Mattes |
|---|---|---|---|
| **Nav-Paradigma** | **Scroll-Spy ohne sichtbares Menü** (dünner Rand-Indikator, verschmilzt mit Horizont-Linie; Logo links + EIN Beratungs-CTA „Beratung 05374-1626") | redaktioneller Erzählfluss als durchlaufendes Magazin, barrierearme Orientierung ohne Bruch | KFZ = Bottom-Bar → hier Scroll-Spy |
| **Sektions-Kopf** | **Großes Zitat als Sektionsstart** (Motto „Ideen umsetzen – Ziele erreichen – Freiheit erleben – Mobilität genießen" + Familien-Story) | Marke erzählt emotional-menschlich; Motto ist echter Anker | KFZ = Frage-Headline + Mini-Dial → hier Motto-Zitat |
| **Komponenten (dominant)** | **Split-Bild-Text-Wechsel** (Bild abwechselnd li/re je Hilfsmittel) **(+ Neben: Step-Ablauf** für Führerschein-Wegweiser) | jedes Hilfsmittel braucht eigenes Bild + erklärenden Fließtext (Verständlichkeit/Barrierearmut) | KFZ = Dotted-Leader-Preisliste → hier Split-Bild-Text |
| **Kontakt-Lösung** | **Karte als Spalte neben Beratungs-Block** (Anruf + WhatsApp links, OSM mit beiden Adressen rechts) | Primärziel = Beratungsanfrage, nicht Standort-Vergleich | KFZ = interaktiver Standort-Umschalter → hier still gelistet |
| **Footer-Form** | **Mega-Footer mit Claim** (Freiheits-Satz + Partner-Logo-Wand Petri+Lehr/Veigel/Bever + Kontakt/Impressum) | Partner-Logowand = echtes Trust-Material; Claim schließt Story emotional | KFZ = einzeilig minimal → hier Mega-Footer |
| **Galerie-Form** | **Große Bild-Bänder als Sektions-Trenner** (Vollbreite-Umbau-/Werkstatt-Fotos + eingebettete Videos) | Original-Bilder + Videos existieren; Atem-Bänder statt Klick-Galerie | KFZ = keine Galerie → hier Bild-Bänder |
| **Sektions-Spine** | siehe unten | Story/Wegweiser/Kostenträger-getrieben (emotional-redaktionell) | KFZ = Preisliste/Reifen/Umschalter (transaktional) |

**Spine:**
`Hero(Split-Story, Bild gleitet rein) → Gründungs-Story(Fließtext-Editorial, Motto-Zitat-Einstieg) →
Bild-Band(Werkstatt) → Leistungs-Welt(Split-Bild-Text-Wechsel, je Hilfsmittel eine Zeile) →
„Der Führerschein"-Wegweiser(Step-Ablauf FeV→Fahrschule→Stelle) → Bild-Band(Video) →
Finanzierung & Kostenträger(Fließtext + Kostenträger-Liste als Trust-Block) →
Team(Porträt-Reihe mit Namen + Gruppenfoto) → Kontakt(Karte-als-Spalte neben Beratungs-Block) →
Mega-Footer(Claim + Partner-Logo-Wand)`

**Divergenz:** 6/6 Achsen vs. Schwester KFZ Mattes · 5–6/6 vs. Südheide/Tierzentrum. Bewusst KEIN
Standort-Umschalter (KFZ-Kern), KEINE Dotted-Leader-Preisliste, KEINE Frage-Headline, KEINE Bottom-Bar.
