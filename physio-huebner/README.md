# Physio Praxis Philipp Hübner — Demo-Website

Statische, voll responsive Demo-Website (Deutsch) für die Physiotherapie-Praxis
Philipp Hübner in Rühen. Per Doppelklick auf `index.html` lauffähig — kein Server,
kein Build-Schritt nötig.

## Dateien
- `index.html` — Seitenstruktur und Inhalte
- `styles.css` — Gestaltung
- `script.js` — Scroll-Animationen, Header, Mobil-Menü
- `assets/` — optimierte Bilder
- `desktop.png` / `mobile.png` — Vorschau-Screenshots (1440 / 390 px)

## Design
- **Schriften** (Google Fonts): Display „Bricolage Grotesque" (Fallback „Archivo"),
  Fließtext „Mulish".
- **Palette**: Weiß `#FFFFFF`, helles Mint `#EEF4F2`, Text Schiefer `#1F2A2E`,
  EIN Akzent ruhiges Petrol/Teal `#2F7D72`.
- Ruhige, helle, vertrauenswürdige Anmutung; SVG-Linien-Icons, viel Weißraum,
  dezente Reveal-Animationen (respektieren `prefers-reduced-motion`).
