# Struktur-Blueprint: Schlaf-T-Raum e.K. · Schlafsysteme & Raumlösungen
(Archetyp A Split-Screen · Welt W1 Editorial-Ruhig · Motion still)

- **Nav-Paradigma:** Split-Screen-Nav — Navigation als eigene linke Hälfte/Spalte im Hero (Logo +
  Traumfänger-Emblem + Anker-Links), rechte Hälfte trägt das große Schlafzimmer-Foto.
- **Sektions-Kopf:** Randständige Marginalie — kleiner vertikaler Label-Text seitlich neben dem Block
  („Sortiment" · „Beratung" · „Angebote").
- **Komponenten (dominant):** Split-Bild-Text-Wechsel — Betten / Matratzen / Bettwaren / Tempur /
  Raumlösungen abwechselnd Bild links/rechts, Zeile für Zeile.
- **Kontakt-Lösung:** Karte als Spalte neben dem Beratungs-/Terminblock — links „individuelle
  Beratungstermine nach Absprache" + Telefon (Inh. Dohmeyer), rechts die Karte (Hauptstraße 43).
  (= zweispaltiger Block Termin/Telefon | Karte, NICHT die alte Mini-Kachel mit Pin-Pille.)
- **Footer-Form:** 3-Spalten + `<details>` (Kontakt · Sortiment · Service/Impressum). Einziges Footer-Vorkommen im Batch.
- **Galerie-Form:** Bento-Grid — unterschiedlich große Schlafzimmer-/Raumlösungs-Kacheln.
- **Sektions-Spine:**
  Hero(Split: Nav-Spalte | Bett-Foto, Masken-Titel) → Sortiment(Split-Bild-Text-Wechsel: Betten/Matratzen/
  Bettwaren/Tempur/Raumlösungen) → Service-Beratung(Marginalie + Text, „individuelle Termine")
  → Ansprechpartner(Porträt-Block Inh. Dohmeyer) → Schnäppchen(Bento-Grid Angebote) → Finden(Karte-als-Spalte
  neben Termin-/Telefon-Block, Hauptstraße 43) → Footer(3-Spalten + `<details>`)

**Divergenz:** Spine ≠ letzte 3/Geschwister ✓ · Nav=Split-Screen-Nav & Kontakt=Karte-als-Spalte (beide im Batch einzigartig) ✓ · 5/6 Achsen abweichend (Footer-Wert klassisch, aber kein Geschwister teilt ihn) ✓.
