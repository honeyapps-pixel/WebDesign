# Struktur-Blueprint: KaminXpress · Frank Dörner Kamin- & Ofenhandel
(Archetyp B Full-Bleed Magazin dunkel · Welt W5 Boutique-Dunkel/Ember · Motion soft)

- **Nav-Paradigma:** Overlay-Fullscreen-Menü (auch Desktop) — Logo + rotes „X" + Burger; Klick öffnet
  ganzseitiges, dunkles Glut-Menü. Vollbild-Bühnen bleiben ungeschnitten.
- **Sektions-Kopf:** Großes Zitat als Sektionsstart — Frank-Dörner-Stimme trägt den Einstieg
  („Wärme, die man sieht." · „Wir freuen uns auf Ihren Besuch.").
- **Komponenten (dominant):** Vollbild-Kapitel — jede Sortiments-Gruppe (Kaminöfen / Zubehör / Holz-Körbe
  / Schornsteine) ein bildschirmfüllender Abschnitt auf schwarzer Bühne (+ Produkt-Showcase-Karten mit
  Marken Lotus/vision im Kaminofen-Kapitel).
- **Kontakt-Lösung:** Karte als Footer-Hintergrund — Adresse (Schloßgarten 7), Öffnungszeiten
  (Mi–Fr 16–19, n.V.) + Betriebsurlaub-Hinweis als heller Daten-Block über dunkel getönter Karte.
- **Footer-Form:** Footer als Kontaktband — der Footer IST die Anfahrt/Öffnungszeiten-Sektion (über Karte),
  darunter nur eine schmale Impressum-Zeile.
- **Galerie-Form:** Vollbild-Slider — ein großes Ofen-/Ausstellungs-Bild zur Zeit (inkl. echtes Storefront).
- **Sektions-Spine:**
  Hero(Video Kaminfeuer-Loop, dunkles Overlay) → Kaminöfen(Vollbild-Kapitel + Marken-Showcase Lotus/vision)
  → Zubehör(Vollbild-Kapitel) → Holz-Körbe(Vollbild-Kapitel) → Schornsteine(Vollbild-Kapitel)
  → Ausstellung-Slider(Vollbild-Slider + Storefront-Foto) → Über-uns(Zitat + Frank Dörner & Team)
  → Kontakt/Anfahrt(Footer als Kontaktband über Karte)

**Divergenz:** Spine ≠ letzte 3/Geschwister ✓ · Nav=Overlay-Fullscreen & Kontakt=Karte-als-Footer-Hintergrund (beide im Batch einzigartig) ✓ · 6/6 Achsen abweichend ✓.
